## Sobre o projeto

O desafio propunha criar uma página capaz de **codificar e decodificar textos** a partir de regras predefinidas de substituição de caracteres.

Apesar do nome usado no desafio, o projeto implementa um **codificador educacional simples**, e não um mecanismo real de criptografia para proteção de dados.

## Regras de codificação

| Letra | Substituição |
| --- | --- |
| `e` | `enter` |
| `i` | `imes` |
| `a` | `ai` |
| `o` | `ober` |
| `u` | `ufat` |

Exemplo:

```text
entrada: ola mundo
saída:  oberlai mufatndober
```

## Funcionalidades

- codificação de textos;
- decodificação do conteúdo codificado;
- validação de entrada em letras minúsculas e sem acentos;
- cópia do resultado para a área de transferência;
- interface construída com HTML e CSS.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

O projeto não possui dependências externas obrigatórias.

1. Clone ou baixe o repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Digite um texto em letras minúsculas e sem acentos.
4. Utilize as opções **Criptografar**, **Descriptografar** ou **Copiar**.

## Contexto

Este projeto foi desenvolvido em **2022** como atividade de aprendizagem. Ele permanece público para preservar o histórico da minha evolução em programação.
